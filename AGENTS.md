# solstone-garmin

Engineering guide for coding agents working in this repository. This file is
the canonical agent guide; `CLAUDE.md` and `GEMINI.md` are symlinks to it. It
holds engineering directives and Connect IQ platform invariants for changing
code here.

## 1. Repository Scope

This repository contains the Monkey C source, resources, build tooling, and
wire-protocol specification (`docs/protocol.md`) for the `solstone` Connect IQ
watch app (API level 6.0.3+, SDK 9.3.0+) targeting the 23 Connect IQ 6.0.3+
microphone watches declared in `manifest.xml`.

This is a public open-source repository. Keep every file, comment, test, and
commit message free of private operational context, internal paths, personal
machine names, and signing keys. Reference only public files in this repository
(for example, `README.md`, `docs/protocol.md`, `CONTRIBUTING.md`,
`SECURITY.md`, `CHANGELOG.md`, `CODE_OF_CONDUCT.md`, and `LICENSE`).

## 2. Engineering Directives

- **Keep the binary lean.** Keep the release `.prg` and static footprint lean
  inside the 64 KB background VM and foreground VM budgets; check
  `--build-stats 0` from `make build`. Do not add speculative layers, unused
  permissions, or helper abstractions without a concrete requirement.
- **Tie UI state to live audio input.** Surface `MIC STALLED` when the stall
  watchdog expires without non-empty chunks (do not hide stalls behind an
  active state). Empty 0-byte audio chunks must never reset the stall watchdog.
  Never overwrite or clear unconfirmed audio when storage fills.
- **Enforce the strict 3-permission allowlist.** Declare only `AudioInput`,
  `Background`, and `Communications` in `manifest.xml` (`scripts/check-format.sh`
  enforces this allowlist in `make format-check`). Never add `Sensor`,
  `Positioning`, `Fit`, `SensorHistory`, analytics, crash reporting, or direct
  internet calls. Never use `ActivityRecording` as a keep-alive hack.
- **Verify against real tool output.** Run `make ci` before committing and
  check compiler output and simulator test results directly.
- **Operator-driven releases.** Store `.iq` packaging and Connect IQ Store
  uploads are operator-driven via `make package DEV_KEY=...`. Do not add
  `.github/workflows/` automation.

## 3. No Data About Real People, in Any Form

No data about real people may enter this repository at any stage: collection,
input, processing, storage, fixtures, output, logs, telemetry, analytics, or
observability. That rule applies equally to de-identified, anonymized,
aggregated, pseudonymized, encrypted, or otherwise transformed derivatives.

- Never commit real voice audio, real watch debug logs, device crash dumps,
  or companion phone captures.
- Every unit test payload in `source/VoiceUnitTests.mc` and every local
  ephemeral signing key generated by the `Makefile` must be wholly synthetic.
- Never commit Connect IQ developer signing keys (`.der`, `.pem`, `.key`).

## 4. Critical Connect IQ Platform Invariants

Violating any of these triggers watch OS reboots (`RTL Trap`), BLE freezes, or
device-specific launch crashes:

1. **ISR-minimal `Audio.Capture` callbacks:** `VoiceCaptureCallbacks.onData()`
   must only append the `ByteArray` reference to its fixed 32-slot RAM ring and
   return in `< 0.5 ms`. Never call `Storage.*`, `Communications.*`,
   `Capture.*`, or heavy allocations inside `onData()`, `onComplete()`, or
   `onError()`.
2. **Initialize `Audio.Capture` once per session:** Call
   `Capture.initializeAudioCapture()` once with the tiny 3-method
   `VoiceCaptureCallbacks` object (never a large controller/app object), always
   passing `Audio.CHANNEL_MONO` and explicit `:windowSize => 2048`. Rotate
   5-minute segments using only `Capture.stop()` -> settle -> `Capture.start()`
   from the foreground `250 ms` master `Timer`.
3. **Strict half-duplex BLE messaging:** Never let watch and phone transmit at
   the same time. Keep strictly one `Communications.transmit(slab, {}, new
   Listener(weakRef, gen))` in flight (always pass `{}` options, never `null`,
   and use a cycle-free `WeakReference` listener per call). Yield the wire
   after setting `FLAG_ACK_REQ` until one cumulative phone ACK arrives. Never
   mix `makeWebRequest` with `transmit` during audio delivery.
4. **No concurrent `Storage` key races and no per-slab `deleteValue()`:**
   - Foreground is sole writer of slots `0..959` and `K_FG_META (-1)`;
     background is sole writer of `K_BG_META (-2)`.
   - While the foreground app runs, call `Background.deleteTemporalEvent()`
     and re-arm on `onStop()` only when unconfirmed slabs remain.
   - Never call per-slab `Storage.deleteValue()` during continuous turnover
     (tombstones cause multi-second flash compaction freezes). Compact via
     `Storage.clearValues()` only when `pendingCount() == 0` (periodically
     after `>= 120` slabs, respecting a `>= 35 s` post-BG-wake guard, on idle
     start reclaim, or on write-error recovery), immediately rewriting metadata.
5. **Keep the 64 KB `(:background)` VM tiny and timer-free:** `VoiceApp` must
   allocate zero foreground objects in `initialize()` or `onStart()`; bridge
   foreground creation through `(:typecheck(disableBackgroundCheck))` module
   functions so foreground classes never enter the background binary. Never use
   `Toybox.Timer` in `(:background)` (`disableBackground = true`); chain
   background sends via `ConnectionListener` callbacks with an iterative
   synchronous-callback trampoline bounded to 22 s.
6. **Guard MIP Solar and multi-watch differences:**
   - Always guard `System.getDisplayMode()` behind `if (System has :getDisplayMode)`
     (MIP Solar watches lack it even though `-l 3` compiles without warning).
   - `ByteArray.decodeNumber(Lang.NUMBER_FORMAT_UINT32, ...)` returns `Long`,
     not `Number`.
   - Maintain 2-button (`enter`, `esc`) and rectangular (`venux1`) usability
     and resolution-matched launcher SVGs (`40`, `54`, `60`, `65` px).
   - Keep `manifest.xml` strictly limited to verified physical-microphone
     devices (do not include Audio-API-only watches that lack a mic).

## 5. Commands

| Target | Purpose |
|---|---|
| `make install` | Verify `monkeyc` and `openssl` availability |
| `make build` | Strict release build (`-r -O 3pz -l 3 -w`) for `DEVICE` (default `fr970`) |
| `make build-debug` | Debug build (`-O 2 -l 3 -w`) keeping `(:debug)` logs |
| `make build-all` | Zero-warning release compile across all 23 watches in `manifest.xml` |
| `make test` | Run 13-test Run No Evil simulator suite across `fr970`, `fenix8solar47mm`, `venu441mm`, `venux1` |
| `make format` | Auto-fix trailing whitespace / line endings and check SPDX headers |
| `make format-check` | Verify SPDX headers, whitespace, and strict 3-permission manifest allowlist |
| `make ci` | Full pre-commit gate: `format-check` + `build-all` + `test` |
| `make package DEV_KEY=...` | Export signed `.iq` Connect IQ Store bundle (requires explicit `DEV_KEY`) |
| `make clean` | Remove `bin/` and generated build outputs |

Set `CIQ_WRAPPER` if your Connect IQ SDK runs inside a container wrapper.

## 6. Code Conventions

- Every `.mc` source file starts with:
  ```monkeyc
  // SPDX-License-Identifier: AGPL-3.0-only
  // Copyright (c) 2026 sol pbc
  ```
- Every `.sh` script starts with a shebang followed by `#` headers:
  ```bash
  #!/usr/bin/env bash
  # SPDX-License-Identifier: AGPL-3.0-only
  # Copyright (c) 2026 sol pbc
  ```
- Do not add SPDX headers to markdown, XML, SVG, or config files.
- Compile with `-r -O 3pz -l 3 -w`. Zero warnings across all 23 devices is
  enforced by `make build-all`.
- Gate debug output through `VoiceProto.vlog()` (`(:debug)` vs empty
  `(:release)`) because `-r` does not strip bare `System.println()` calls.
- All unit tests live in `source/VoiceUnitTests.mc` annotated `(:test)` so zero
  test bytecode ships in release builds.
